# 予備実験の実行環境

確認日：2026年9月20日。Windows 11、Python 3.12.10、NVIDIA RTX 5060 Ti（専用VRAM 15.93 GiB）。`.venv` はGit対象外。PowerShellの `python` はWindowsApps aliasに当たる場合があるため、以下では仮想環境の実行ファイルを直接使う。

PyTorchは通常のPyPIから導入すると、この環境ではCPU版になった。CUDA版は[PyTorch公式ホイール](https://download.pytorch.org/whl/cu130/torch/)から導入する。現時点の確認済み組み合わせは `torch 2.14.0+cu130`、`transformers 5.17.0`、`accelerate 1.15.0`、`bitsandbytes 0.50.2`。再構築時はまずGPU・ドライバとの互換性を再確認する。

```powershell
& 'C:\Users\kohet\AppData\Local\Programs\Python\Python312\python.exe' -m venv .venv
& '.\.venv\Scripts\python.exe' -m pip install --index-url https://download.pytorch.org/whl/cu130 'torch==2.14.0+cu130'
& '.\.venv\Scripts\python.exe' -m pip install 'transformers==5.17.0' 'accelerate==1.15.0' 'bitsandbytes==0.50.2'
& '.\.venv\Scripts\python.exe' -c "import torch; print(torch.__version__, torch.version.cuda, torch.cuda.is_available(), torch.cuda.get_device_name(0))"
```

最終コマンドで `True` と `NVIDIA GeForce RTX 5060 Ti` が出た。モデルの重みはリポジトリ外へ公開しない。下記の `HF_HOME` はこの作業フォルダのGit除外キャッシュに置くための設定。

```powershell
$env:HF_HOME = Join-Path (Get-Location) '.cache\huggingface'
& '.\.venv\Scripts\python.exe' tools\smoke_tokenizer.py
& '.\.venv\Scripts\python.exe' tools\smoke_generate.py
```

モデルは[Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) の固定revision `b968826d9c46dd6066d109eabc6255188de91218` を予備候補にした。これを主モデルに採用するかは、推論時間と出力保存の動作確認後に決める。予備スクリプトの出力は最終の性能指標として使わない。

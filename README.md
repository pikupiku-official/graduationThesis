# CMHG研究 卒業論文

中国少数民族言語の記事見出し生成（ニュース・政府文書等を含む）を対象に、軽量LLMがどの局面で性能上の制約を示すのかを分析する卒業論文の作業リポジトリです。

## 現在の研究テーマ

CMHGを用いた中国少数民族言語における軽量LLMの性能上の制約分析

副題：見出し生成・見出し選択・翻訳媒介処理の比較から

中心課題は、記事本文と見出しの内容対応の判定、対象言語での生成・表記、出力制御のうち、どこで制約が現れるかを生成課題と選択課題の比較から調べることです。比較だけで因果原因を確定したとは主張しません。

## このフォルダの使い方

- `docs/計画整理.md`: 研究目的、問い、仮説、未決定事項、優先順位
- `docs/実験設計.md`: データ、比較条件、評価、エラー分類、再現性のルール
- `docs/文献調査.md`: 一次情報を確認した先行研究・データセット・注意点
- `docs/進捗管理.md`: 作業チェックリストと判断ゲート
- `docs/診断研究プロトコル.md`: 今回決めた診断フロー、実験優先順位、締切からの逆算
- `docs/CMHGデータ監査.md`: 固定revisionの注釈済みデータ監査と残る注意点
- `docs/環境構築.md`: WindowsのPython・CUDA環境と予備実験の再実行手順
- `docs/予備実験メモ.md`: 3言語各20件の動作確認結果と未解決の実験条件
- `docs/補助的内容評価プロトコル.md`: 研究者＋辞書・LLM補助による少数例レビューの手順と限界
- `docs/Grill-me研究計画.md`: 質問への回答と未解決事項の記録
- `references/references.bib`: 参考文献のBibTeX
- `data/raw/`: ダウンロードした生データ。容量が大きいためGit対象外
- `data/processed/`: 前処理後データ。再生成できるものはGit対象外
- `experiments/`: 実験設定、プロンプト、実行条件
- `results/`: 集計表、図、分析メモ
- `paper/`: 本文の草稿、図表、提出用ファイル

既存の計画書原本 `2026年度演習論文計画書_黒部成智.docx` は、現状のままルートに保持しています。

## 当面の優先順位

1. 予備実験で多発した出力上限到達と入力切り詰めに対し、本実験の条件を固定する
2. 確認済みの全量データと注釈済みデータの本文一致を学習から除外し、近重複も調べる
3. 資料種別と実行可能性を確認して主実験の対象言語とモデルを固定する
4. 同じ記事で生成、選択、トークン化、出力失敗率を測る
5. 翻訳媒介を比較し、可能ならQLoRAの少量適応を試す

研究の成果物は、各比較の結果から失敗要因の候補と未解決の交絡を示す診断フローです。計画と締切は[診断研究プロトコル](docs/診断研究プロトコル.md)を参照してください。

## Git運用

実験設定、コード、集計表、論文草稿はコミットします。データ本体、モデル重み、アクセストークン、実験ログの大量出力はコミットしません。データ取得元、リビジョン、ハッシュ、実行コマンドは必ず記録します。

このリポジトリは初期準備用で、GitHubなどのリモートはまだ設定していません。

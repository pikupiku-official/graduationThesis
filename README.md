# CMHG研究 卒業論文

中国少数民族言語のニュース見出し生成を対象に、7Bから14B級の軽量LLMがどの局面で性能上の制約を示すのかを分析する卒業論文の作業リポジトリです。

## 現在の研究テーマ

CMHGを用いた中国少数民族言語における軽量LLMの性能上の制約分析

副題：見出し生成・見出し選択・翻訳媒介処理の比較から

中心課題は、モデルがニュース本文の内容を理解できていないのか、内容はある程度処理できても対象言語で見出しを生成・表記できないのかを、生成課題と選択課題の差から切り分けることです。

## このフォルダの使い方

- `docs/計画整理.md`: 研究目的、問い、仮説、未決定事項、優先順位
- `docs/実験設計.md`: データ、比較条件、評価、エラー分類、再現性のルール
- `docs/文献調査.md`: 一次情報を確認した先行研究・データセット・注意点
- `docs/進捗管理.md`: 作業チェックリストと判断ゲート
- `references/references.bib`: 参考文献のBibTeX
- `data/raw/`: ダウンロードした生データ。容量が大きいためGit対象外
- `data/processed/`: 前処理後データ。再生成できるものはGit対象外
- `experiments/`: 実験設定、プロンプト、実行条件
- `results/`: 集計表、図、分析メモ
- `paper/`: 本文の草稿、図表、提出用ファイル

既存の計画書原本 `2026年度演習論文計画書_黒部成智.docx` は、現状のままルートに保持しています。

## 当面の優先順位

1. 実行環境とGPU資源を確認する
2. CMHGを固定リビジョンで取得し、ファイル構成・列・ライセンスを監査する
3. 対象言語を2言語に確定する
4. 1モデルのベースラインで生成、選択、トークン化を小規模に再現する
5. ベースラインが成立した後に翻訳媒介処理とQLoRAを追加する

## Git運用

実験設定、コード、集計表、論文草稿はコミットします。データ本体、モデル重み、アクセストークン、実験ログの大量出力はコミットしません。データ取得元、リビジョン、ハッシュ、実行コマンドは必ず記録します。

このリポジトリは初期準備用で、GitHubなどのリモートはまだ設定していません。
